# Citation Rules — 零幻觉取证与引用规范

这是本 skill 最重要的文件。用户用它建立对学者的**可信**认知；一句编造的"事实"
比少写十句话伤害大得多。读完再开始 Phase 1。

## 1. 先证据，后行文：证据表

调研时**先填证据表**，再写报告。报告里的每句结论必须能在表里找到对应行。

| # | 待写结论（一句话） | 来源 URL | 原文摘录（≤2 句，支持该结论） | 可信度 |
|---|---|---|---|---|
| 1 | LeCun 1987–88 在 Hinton 组做博士后 | https://… | "...did a postdoc with Geoffrey Hinton..." | A |
| 2 | … | … | … | … |

没有"原文摘录"那一格 → 这条结论不许进报告。摘录必须**真实出现在该 URL 页面**，
不要凭印象填；抓不到页面正文就别声称它说了什么。

## 2. 来源可信度分级

| 级别 | 例子 | 用法 |
|---|---|---|
| A 权威一手 | 本人主页/CV、Google Scholar profile、官方获奖页（amturing.acm.org 等）、Math Genealogy、DBLP、机构官网、毕业论文 | 可直接作为结论依据 |
| B 可信二手 | Wikipedia、知名媒体深度报道、IEEE/ACM 讣告或人物报道、学会 Fellow 名录 | 可用，优先再找 A 印证关键事实 |
| C 弱 | 个人博客、论坛、未署名汇编、AI 生成内容农场 | 不单独作为事实依据；只能作线索去找 A/B |

关键事实（导师是谁、得过什么大奖、引用量级）尽量有 A 级，或 ≥2 个独立 B 级互证。

## 3. 内联引用写法

每个**结论句**后紧跟来源链接，链接就贴在该观点下/后面：

- 单句：`他于 2018 年获图灵奖。[来源](https://amturing.acm.org/...)`
- 一段多句同源：段末统一 `[来源](URL)`，但段内不得混入无源的新结论。
- 一条结论多源：`……。[来源1](URL) [来源2](URL)`
- 数字指标必须带快照日：`总引用约 35 万（截至 2025-05，会变）。[来源](Scholar URL)`

## 4. 找不到可靠来源时（用户已拍板的规则）

**写出该信息，但显式标注 `〔未找到可靠来源〕`**，绝不伪装成已证实：

`据多处非权威说法其博士导师为 X，但未找到可靠出处证实。〔未找到可靠来源〕`

适用：你认为可能为真/对用户有用、但只有 C 级或查不到出处的内容。
完全没有任何线索的内容：直接不写，不要硬凑。

## 5. 类比与推断必须显式标注

- 跨领域类比（"评价"段帮助用户建立直觉）：标 `〔类比·主观〕`，并写出类比依据
  （如"同为各自领域最高奖得主"），强调是直觉而非等价事实。
- 由事实推出的判断（非直接陈述）：标 `〔推断〕`，并给出推断所依赖的、各自有来源的事实。
- 区别：事实有出处链接；类比/推断有标注 + 底层事实链接。三者在文中视觉上要可区分。

## 6. 自检清单（Phase 2 写完必过）

1. 逐句扫：每个结论句是否有 `[来源]` 或 `〔未找到可靠来源〕`/`〔类比·主观〕`/`〔推断〕`？
2. 每个来源链接是否真的支持紧邻的那句话（不是凑一个相关 URL）？
3. 数字指标是否都带快照日期？
4. 关系图里写成实边的关系，是否每条都有 source（无源的应是 inferred 候选）？
5. 有没有"看起来合理但其实没查过"的句子？有 → 删或标注。
